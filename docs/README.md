# remitbtc Documentation

Comprehensive documentation for the remitbtc project: a React Native + Firebase + Breez SDK Lightning remittance app.

- Audience: developers integrating, extending, or contributing to remitbtc
- Scope: architecture, public APIs, modules, and usage examples

## Structure
- `index.md`: Documentation home and quick links
- `architecture.md`: High-level system overview
- `configuration.md`: Environment and service configuration
- `api/`: Public APIs, components, and modules
- `examples/`: End-to-end usage examples
- `contributing.md`: How to propose changes to docs
- `glossary.md`: Domain and project terminology

## Conventions
- Code is JavaScript/TypeScript unless otherwise noted
- React Native components are written with functional components and hooks
- Use of Breez SDK may require native setup steps on iOS/Android
